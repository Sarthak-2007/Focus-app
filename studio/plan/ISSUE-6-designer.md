## §0 · THE STRIP — CONSUMPTION ONLY (issue #4's cell owns it)

The top status strip is NOT redesigned here, in whole or in part.
My composition consumes whatever strip lands, under four rules:

1. The strip is host chrome. It sits above the Deck's scroll column;
   the Deck neither reserves a named slot for it, duplicates any
   fact it prints, nor changes height when it changes.
2. Whatever the strip's final height `S` is, it enters the chrome
   budget in §1 as a variable, not a constant. Every dp the strip
   grows is a dp the Deck does not get back elsewhere — the budget
   below is written so the Deck side still balances at any `S`.
3. If the strip prints blocking health, the Deck prints it ZERO
   additional times in health (D9's drawer law already does this:
   a healthy wire is silence on the Deck). If the strip does not
   print it, the Deck still does not grow a standing cell for it —
   BLOCK remains state-only (drawer / fault) either way.
4. No Deck element aligns to, echoes, or visually pairs with the
   strip. The first Deck-owned pixel is the instrument. A reader
   should be able to cover the strip and lose nothing about how
   the Deck itself is read.

The same consumption rule applies to the header band / Guard line
(audit §3: host chrome, PARK's door, counted in the pile-up because
the eye cannot tell host from home) and to the rail (F20's PARK
print is the rail's own fix, not Deck furniture).

## §2 · ONE QUESTION PER STATE — KEEP as the presentation of record (Plan §7, audit §8)

**Disposition: KEEP, adopted whole, and specified to the element.**
The Deck asks exactly one question per state; every fact lives in
the room that owns its answer. Layouts below are top→bottom,
Deck-owned elements only (host chrome per §0 sits outside them).
Fonts throughout: Sora for display, Atkinson Hyperlegible for
body/title text, Anonymous Pro for every number, recipe, and
telemetry print. No green or near-green anywhere. No element
prints a state the machine has not verified.

### IDLE — "How long, and into what?"
Scroll column (no scroll needed at 740dp — this is an acceptance
test, not a hope):
1. The instrument (D8 Fusion form; interim form D3–D5): wheel
   288dp, hub prints the true span + break sub-line.
2. The instrument's foot line, centred, Anonymous Pro 11sp,
   quiet ink: `ENDS 14:30 · PLANNED` for a timed set (the word
   PLANNED is F21's cure for the sliding idle ENDS, audit §5.5 —
   a plan is labelled a plan, never printed as a fact about the
   future), or `NO END` for FLOW.
3. Ghost task title (D7): one line, read-only.
4. *Nothing else.* No utilities, no strip cells, no sentence.
Pinned: slide (72dp, its words live — D11) + imprint. The imprint
is the one line beneath the slide: LIVE wire → the seal's promise
(tenant); non-LIVE wire → the refusal sentence takes that same
line's tenancy instead of reserving a second slot. Healthy wire,
healthy silence: the drawer is shut and BLOCK is printed nowhere
on this face.

### PROVING — "Is it holding?"
1. Instrument, frozen exactly as set (wheel locked, hub span as
   dialled). Nothing on the face starts a readout on an unproven
   seal.
2. Proof drawer OPEN where the ghost title stood (D9): the three
   cells + seam, in the drawer's own frame.
3. Ghost title is displaced, not stacked — the drawer takes its
   room; the title returns at settle.
Pinned: slide still seated at its address (Δy = 0); imprint
latched from the press. The drawer holds for the proving seconds
plus ONE settle beat after success, then collapses — proof gets
the whole stage for exactly the seconds it is the question, and
not one frame longer.

### JAMMED / FAULT — "Is it holding?" (answer: not proven)
As PROVING, with three changes: the jam/refusal sentence prints
INSIDE the drawer (its wording is F9's, its room is mine); the
pinned stack grows the sentence above the slide as well only if
the fault survives the drawer state into idle (D10 — in a live
jam the drawer IS the stage and the pinned copy would be a second
rendering of one fact, which §4 of the audit convicts); the
instrument stays frozen. Fault is the loudest Deck state by
design — more room, first position — and health is the quietest.
That inversion is the hierarchy working, not an exception to it.

### RUNNING — "How long left, and what's in the way?"
1. The instrument, sealed in place (D8): the wheel does not
   vanish or hand over — the hub is now the ticking readout,
   same glyph, same address; rim ink carries progress. There is
   no progress track and no % anywhere on the face (D4).
2. Foot line: `ENDS HH:MM` derived from the stored end only
   (audit §5 acquittal — a pure function of a stored end is the
   one honest ENDS), no PLANNED label: running, it is a fact.
3. Ghost task title + DONE key-cap (D7).
4. Utilities row (D6): DESK CLOCK · HELD, running only.
Pinned: the STOP chair at the slide's address, full 72dp (D11);
imprint as the foot, tenant struck at full alpha, carrying the
app count's only standing rendering.

### BREAK (a running sub-state, with its own question: "How long is my break?")
The audit's 1 AM test (§6) convicts the current form: the break's
length is the smallest print on the card while the hero answers a
different question. Ruled composition:
1. The hub IS the break: the hub readout becomes the break
   countdown — the largest print on the face answers the state's
   one question (F5's "the hero IS the break," restated for the
   Fusion's address).
2. Hub sub-line / foot line: `BACK AT HH:MM` (F5's eyebrow words,
   moved to the foot line's tenancy — the eyebrow itself does not
   survive the Fusion, D3).
3. END BREAK chip, full width, in the utilities' room (the
   existing ST-02 seating is correct; it stays).
4. Everything else as RUNNING. The grace countdown, while it
   runs, likewise lives in the hub (F6) — the countdown belongs
   to the instrument, never to a chip badge.

### FINISH-DETAINED / RECEIPT — KEEP as now (audit §8: both acquitted)
Held last frame; receipt slip dismissible by slip-swipe or
PARK/rail only, a stray scrim tap shakes the slip and never kills
it (F19, **S**). No composition change beyond what the Fusion does
to the held frame's instrument (it is the wheel-as-clock, frozen).

### ROUTINE-BORN sessions
A routine-born session (e.g. SLEEP) is born RUNNING and must not
be indistinguishable from a hand-armed one (audit §6). With the
eyebrow dead (D3), its name takes the foot line's first position
for its whole life: `SLEEP · ROUTINE — ENDS HH:MM`, Anonymous Pro
10sp, quiet ink. One line, no badge, no second rendering.

## §3 · ELEMENT DISPOSITIONS

### D1 · The wheel — KEEP, at full size
288dp, unchanged, never shrunk to buy room (room comes from

### D2 · The FLOW key-cap — STRIKE as a control; its print successor — CHANGE
As a control it is theatre (writes a preset the engine never
reads, audit §5.1) — struck, no replacement door. FLOW becomes
wheel-only: dial below 10 minutes and the mode is what the hub
says it is. The mode is PRINTED at the instrument, never hidden
in a number range: hub primary reads `FLOW`, foot line reads
`NO END`. That print is the cap's successor and the only one.
Interim (pre-Fusion, current room): the recipe line of D3 carries
the mode until the hub can. Price: **S** (F2's print half).

### D3 · The eyebrow — STRIKE as a standing label; the recipe — CHANGE of address
Standing `TOTAL` / `SESSION RUNNING` are wallpaper and die; the
fake day emboss shadow dies with them (audit §3, Schein T1).
The one job the eyebrow earned — explaining the hero's arithmetic
(audit §5.6: span = blocks × block + (blocks−1) × 10, true and
nowhere on the face) — moves INTO the instrument:
- Interim form (lands on the current room, F4, **S**): the idle
  eyebrow prints the recipe and nothing else: `3 × 50 + BREAKS`.
  In break: `BREAK — BACK AT HH:MM` (F5). Routine-born: the name

- Final form (with F18): the eyebrow line is deleted. The recipe
  lives in the hub as its sub-line (D8): `+10 BREAK` when
  blocks > 1, the block pattern `3 × 50` as the hub's quiet
  second line at idle. No fact is lost; its address moves to the
  hand that sets it (Vega A, adopted).

### D4 · Progress — STRIKE the track and the %; CHANGE to rim ink
The % text is killed (unanimous). The track is killed in the
Fusion form: progress is ink filling the wheel's tick ring —
elapsed/target, filling, no floors, no inversion (F3's truth
terms, **S**, apply to the interim track until the rim lands).
FLOW gets NO rim progress and no bar in any form: NO END means
no denominator, no floor, no completion. A ring that can never
complete must never pretend to fill toward anything.

### D5 · The hero glyph — KEEP as the page's single numeral; CHANGE to single-press; then CHANGE of address (the Fusion)
- Single-press (F10, **S**): the catch ghost dies. One shadow
  ghost survives, tokenised per scheme, one direction only.
  Ghosts are OFF entirely on FLOW and on any ticking readout —
  a press does not strike a moving target, and tired eyes read
  ghosts as blur. Fallback if it still reads soft on device:
  Dens's kill-both. The static MM:SS standing for hours is also
  an OLED burn-in exposure the AOD clock already dodges — the
  ticking hub inherits the AOD's shift discipline (builder to
  confirm the mechanism exists view-side; the *requirement* is
  recorded here).
- Address: at the Fusion the glyph's tenancy ends as a panel
  element and begins as the hub's (D8). It remains the page's
  single numeral at every step — there is never a frame with
  both a hero numeral and a hub numeral.

### D6 · Utilities row — KEEP, state-gated, quietened

Price: **M** (F7, unchanged — the moves to Tasks are the lane).

### D8 · THE FUSION — CHANGE, adopted as the instrument's final form (Vega A; F18, M)
The dial becomes its own clock. Concretely:
- The hero PANEL dies: no card, no eyebrow line, no separate
  readout row. The wheel stands on the ground as the Deck's one
  instrument. (Consequence for F11: the card-shadow item is an
  interim cure for the current room only — **S** if it lands
  before the Fusion, struck as moot after; a ground-standing
  wheel claims no lift and needs none.)
- The hub is the readout, in three lives at ONE address, same
  glyph family (Sora display), same centre:
  - *Idle:* primary line = the true span, breaks priced in
    (`1H 50M`); sub-line (Anonymous Pro 10sp, quiet) = the
    recipe remainder (`+10 BREAK` when blocks > 1; `3 × 50`
    pattern at idle). The wheel's numerals still set minutes;
    the hub still cycles block count by its gesture — but the
    count is now PRINTED in the sub-line, so the gesture is no
    longer secret: what the hub hides today, the hub's own face
    declares.
  - *Sealing:* the wheel does not vanish, swap, or hand over.
    It locks at its seat. Δ-address = 0 across the seal, same
    law the slide already keeps.
  - *Running:* the hub is the ticking readout (MM:SS), same
    glyph, same size class as the idle span — the eye never
    re-finds its clock. Rim ink carries progress (D4). FLOW:
    hub counts up, ring never completes.
  - *Break / grace:* hub carries that countdown (§2), because
    in those states it IS the question.
- Hierarchy consequence: with the panel gone, brightness order
  is glyph > tick ring / hub > controls > ground (D13) — one
  lit object on the face, where today three dark masses shout
  (audit §6, Schein).
- What dies with the panel, finally and completely: hero card,
  eyebrow as standing label, progress track, %, and the whole
  progressFraction derivation (audit §8). If any of the five is
  still composable after F18 lands, the Fusion has not landed.
Price: **M** (F18, unchanged). Lands together with F16 (§1).

### D9 · The proof strip — STRIKE as a standing band; CHANGE to the state-gated proof drawer
The band dies as a permanent object (audit §3). Its facts split

- App count: its standing home is the imprint tenant (already

  health it is printed zero times on the Deck face (§0 rule 3

- The drawer itself: Plan's form, Dens's law. It occupies the
  ghost title's room in the scroll column (between instrument
  and pinned stack), contains the strip's three cells + seam
  in one frame, exists ONLY in PROVING / JAMMED / idle-fault and
  for one settle beat after proving. It never takes pinned
  tenancy, never reserves height while shut — a shut drawer is
  0dp, not a reserved slot.
Price: **L** as part of F16; Dens's Two-Height Strip remains the
priced floor (**M**-class fallback) if the drawer is refused at
merge — recorded, not ruled.

### D13 · Hero/quiet hierarchy — CHANGE (F10–F13, F15; token terms for F17)
The finish law for every Deck frame, in one paragraph and four
rulings: **brightness and size order must equal importance order
— glyph > instrument > controls > ground — in every state
except fault, where the sentence/drawer deliberately outranks
the instrument** (fault gets the stage; that is D9/D10, not a
hierarchy failure).
- F12 (**S**): utilities' night fill steps down (the audit names
  #2A2320; in the final code this is a scheme TOKEN, never a raw
  hex — see F17 term below). Ink fills that today outshine the
  hero card are demoted below it.
- F13 (**S**): key-cap radii registered — 8dp → 12dp for DONE
  and any successor key-cap print; two radii app-wide on this
  screen, no third.
- F15 (**M**): the vertigo moves to the GROUND. At the seal the
  page recedes — ground scale 0.98, blur peak 3dp, same curves,
  same 1050ms — and the instrument seals IN FOCUS. A shot that
  blurs the thing being sealed is a gimmick; a shot that stills
  the room around it is a ceremony. Under the Fusion this reads:
  ghost title, utilities, and ground recede; the wheel never
  blurs, never scales.
- F17 term (the sweep itself is the finisher/builder's, **M**):
  the tokens the sweep must produce for this screen are exactly
  the hierarchy's four ranks — heroGlyph ink, instrument ink,
  control ink/fill, ground — per scheme, plus the single-press
  ghost token (D5). If a Deck colour cannot be named as one of
  those ranks, it does not belong on the Deck.
- Acceptance instrument: Schein's Lamp Test is endorsed as the
  check — three pure-luminance frames (idle / sealed / fault);
  idle and sealed must read as a monotonic staircase in the
  order above, fault must show the drawer/sentence on top.
  Tonight's Deck fails it at the sealed frame (audit §8).
