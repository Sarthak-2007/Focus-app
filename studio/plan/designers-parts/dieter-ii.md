# DIETER-II — Designers, Industrial (Rams) seat · Coordinator: Sana
## PLAN WAVE — THE DUPLICATION & NECESSITY AUDIT (checklist, no code)

**How to run this audit:** take the finished plan (or the built app), go fact
by fact down §1 and element by element down §2. A fact found anywhere except
its one home = FAIL. An element that cannot pass its one-sentence test =
STRIKE. A screen whose resting voice exceeds ten words in §3 = FAIL.
No exceptions are argued at audit time; exceptions are argued to Sana
beforehand, in writing, or they do not exist.

Settled law enforced throughout, not re-argued: ARM ≤10s · HOLD absolute ·
TRUTH once · one fact, one rendering · hub = pips only · drawn sleds only
where travel is the function, elsewhere state is a word · radius 8/16 ·
one COMMIT fill per screen, orange type banned everywhere · chrome is not
content · fonts / staircase / spacing / margin 20dp locked.

## §2 — THE NECESSITY STRIKES

**The test, one sentence per element:** *what question does this element
answer, at this moment, that nothing else on this screen already answers?*
No answer, a duplicate answer, or an answer nobody is asking at that
moment — it dies. Survivors in wave 1 earned a one-sentence pardon each;
the pardons stand only while the sentence stays true.

## §3 — THE TEN-WORDS-OR-LESS TEST, every screen at rest

**Counting method (fixed, so the builder counts identically):** count
*words the app speaks* in the resting state — labels, state words, verbs,
sentences. Numerals, clock times and dates are not words. User-authored
strings (task titles, app names, routine names, the intention line) are
not the app speaking and are excluded — they are content, listed in §1.
Band-nav stop words are addresses, not statements, and are excluded;
if a future audit counts them, every screen gains the same constant and
the ranking does not change. Lists are tested on their *furniture*
(headers, section words, verbs) — each row's state word is that row's
fact (F14/F11), not screen narration.

- [ ] Every numeral on the screen traced to exactly one §1 row.
