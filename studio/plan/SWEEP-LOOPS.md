The 7-day stat is safe in practice (~3 sessions/day ⇒ 60 ≈ 20 days), but the read itself is a cap on the record, inherited from before the permanence standard existed. |
| 2 | Intercept logs **LIMIT 80** | MonolithDao.kt:134 (`getInterceptLogsFlow`) — the only list read of the table | Repository.interceptLogsFlow (:85) → VM interceptLogs (:359); VM.totalInterceptions (:436) | **List hides; the count survives.** Individual entries past the newest 80 vanish from any list surface. The receipt's deflection read is window-scoped and uncapped (Dao, `timestampMillis >= :fromMillis`). No delete path for intercept_logs rows exists. |
