# TRUTH AUDIT — Deck, Chrome, Shield (current code, Oct 29)

**Auditors:** Vera (hierarchy) + Una (consistency), Critics cohort. Coordinator: Hale.
**Scope:** every number and factual string rendered on the Deck (`TactileDeckScreen.kt`),
the chrome (`MainActivity.kt` header / drawer / bottom nav, `MonolithCustomComponents.kt`),
and Shield (`ShieldMatrixScreen.kt`), chased to its source field/function in
`MonolithViewModel.kt`, `MonolithRepository.kt`, `MonolithModels.kt` and the two
enforcement services. Standard applied: TELL THE TRUTH once, in human language —
one fact, one rendering.
**Verdicts:** TRUE / LIE / STALE / DUPLICATE-RENDERING.

Headline count: the session's duration is rendered **five different ways on the Deck
alone**, and in the default state (dial 50, 2 blocks) three of them disagree with
each other and the fourth disagrees with what `startSession` will actually run.

## Worst finding

**One sentence:** On the default Deck the user slides a thumb badged `50M` under a caption promising `100 MIN TOTAL` and a finish time an hour early — and if he found FLOW first and then turned the wheel, the screen swears `NO LIMIT` while the engine arms a hard 50-minute countdown: the Deck's five renderings of one duration disagree with each other, and two of them disagree with the session that actually runs.
