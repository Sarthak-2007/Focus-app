   shows BLOCK LENGTH (25:00 at 84sp) while the TOTAL sits in a 10.5sp

   It is the only caller of `selectStudyPreset` in the app; one tap sets

   timed session underneath. No exit exists short of killing the app.
   Its tap is also voiced twice (latch + phantom wheel detent).

   15/30/45, slip drains — is not in code. `Emergency60sValveView` still
   zeroes on release while its header comment claims decay, and its readout
   counts only the current grip.
4. **Routines mint ghost minutes (Reihe).** A routine START with no session
   active creates a full session for the whole window — phone in a drawer,
   minutes accrue as study. A manual session at the boundary makes START
   silently do nothing. Disabling a live routine cancels its own END alarm.
   Printed duration doesn't exist; `durationMinutes()` coerces 15–720 while
   the editor clamps 30–720, so print and run length can disagree.
5. **The loadout band's shipped ★ drifted (Fader).** The cap marker now
   draws `tokOnControlFill()` (night #FFE4CF — the text-only cream) instead
   of the pinned constant, and the wave-1 sequencing bug lives line-for-line:
   type + apply fire at ACTION_UP, the cap lands 280ms later.
6. **The nav violates HOLD today (Band).** Mid-session the band stays fully
   live — every destination one tap away under a sealed session. And on
   Guard (`selectedTabIndex = -1`) the pill vanishes instantly: the
   selector deletes itself exactly where orientation matters most.
7. **The fallback task lie (Zeile + Linea, joint).** When nothing is
   active, index 0 renders ACTIVE + orange START on both Tasks §3 and the
   Deck NOW line. Both surfaces agree — and both may be lying.
8. **Search loses to scrolling at the shipped list size (Fenja, counted).**
   At SHOWING 12, scroll-to-any-app ≈1.0–1.8s vs search path ≈3.5–5s.
   The field is long-list insurance, not furniture; the ladder demotes it
   (36dp sticky) instead of promoting it, and states its deletion condition.

   both states — the screen's verbs are already text (START, DONE, DEL),
   a collapsed ADD must be able to submit retained text in one tap (the
   sticky line's reason to exist), and Taste's strongest point (a text

   by dropping the travel, not the word. The **card punch becomes THE

   Taste's caps ladder stands untouched; with no ink verb in the bank,
   his ★ gets cleaner. **Duration echo:** lives in the collapsed line
   only; in expanded state the latched cap (position + marker) is the
   rendering and the echo hides — one fact, one rendering, per state.

   stands.** Gate, printed pocket, and commit line must be one fact; a
   gate the eye crosses before the hand commits is a second threshold to
