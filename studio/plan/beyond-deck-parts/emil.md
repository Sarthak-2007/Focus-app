## The beauty case, in plain words

A printed line earns trust the way a nameplate on a machine does: it says the same kind of thing, in the same type, in the same place, every day — and when the thing it says changes, it changes because the world changed, not because the screen felt like performing.

The imprint's state slot has never been typeset that way. It has been three men's luggage in one rack: my state word, Suki's health sentence, Rosa's refusal, a count that wandered between tenses — `SHUT 7 APPS` printed while nothing was shut, a small lie told in good type, ten times a day. Each tenant arrived with its own size, its own home, its own idea of when to speak. Read cold, at 03:30, that is not a line. It is a queue of interruptions wearing the same coat.

Set as one object, it becomes the Deck's colophon: one baseline, one type, one column of numerals, four tenses of a single fact — *what this seal will stop, what it is stopping, and the mornings it can stop nothing.* The beauty is not decoration. It is that at 04:58, half awake, he reads a line that has not dressed up for the dawn, has not shrunk for the emergency, and has not learned a new voice for the seal. The line he trusted idle is the line that refuses him, word for word already in front of him before his thumb moved. A refusal you have already read is not a surprise. It is a fact arriving on time.

And when the arm lands, the line does not swap like gossip. It is struck — once, in the open, with the pressure lip a press leaves under type it meant. Then it holds still for the whole session, because that is what it says it is doing.

## 1 — THE SLOT, TYPESET AS ONE OBJECT

### 1.1 The object

One variable segment of the imprint line, and nothing else in the imprint moves to accommodate it.

- **Position.** Inside the shared **20dp margin**, on the imprint's microtype baseline — **10dp below the double rule**, the rule itself under the masthead (masthead baseline 22dp, total header 52dp as filed). The slot's box is fixed: left edge at the 20dp margin, right edge at the column's right terminus (20dp from the screen edge), height **12dp**. Tenancy changes never reflow the masthead, the rule, the registration cross, or anything below the line. The Deck's composition does not breathe because a word changed.
- **Type — the plate, no exceptions.** Anonymous Pro **700** (true Bold file), **10sp**, tracking **+2.0**, line height **12**, all caps, pressed ink (glyph edges full density, centres 82% easing to 88% as ink settles — the treatment from my receipt, at furniture scale). The plate floor is law: **nothing on the Deck prints below 10sp, and this slot never prints above it either.** It is one size in health, in refusal, and in seal. Emphasis in this object is carried by *tier and tense*, never by size.
- **Numeral discipline.** One numeral column: Anonymous Pro's tabular figures, one fact per string. The only string allowed two numerals is the partial count (`6 OF 7 …`), where both numerals are the numerator and denominator of the *same* fact, set in the same column. No clock time, no date, no check-count ever prints in this slot.
- **Night tiers (locked staircase, no colour anywhere).** Healthy and sealed tenants: **#9C8E84** (secondary tier). Truth tenant: **#D2C6BB** (primary tier) — one step stronger, Suki's rule: the failure is heavier, not redder, not larger. Glyph tier **#EDE3D8** is never spent here; it belongs to the hero and the reader dot. Day: the same relationships in the day staircase (healthy/sealed at the ≈5.6:1 tier, Truth one tier stronger).
- **Single line, honestly.** Every string below is ≤39 characters. At plate metrics (6dp advance + 2.0 tracking ≈ 8dp/char) the longest string in this spec occupies 312dp of the 320dp reference column. **No string wraps, truncates, or compresses its tracking at reference scale.** At system font scale ≥1.3×, the slot — and only the slot — may take a second 12dp line, growing the header by 12dp and pushing the Deck down intact; a fact is never shortened to save a layout.

### 1.2 The tenancy law

One slot, four tenants, ranked. A higher tenant evicts a lower one completely — the slot never prints two tenants, never concatenates, never appends a warning to a healthy string.

1. **TRUTH** (Suki's) — blocking health is broken or unproved. Evicts every unsealed tenant, in idle and primed alike.
2. **SEALED** — the seal is live. While sealed, *no tenant evicts this one, not even TRUTH*: a permission revoked mid-session does not reprint the slot (HOLD — no mid-session prompt, no competing surface; the failure surfaces at unlock and on the receipt, per Suki's own gap law). The sealed string is a fact about the seat frame, frozen — see §1.4.
3. **PRIMED** — a routine has seated the Deck. This tenant is *the healthy string itself*, re-measured against the routine's loadout. Priming changes the Deck's composition; it does not change this line's grammar, tense, or voice (§1.3).
4. **IDLE** — the healthy string, loadout as last set by the rested user.

The armability question — which failures hard-stop the slide and which pass as advisory — is Rosa's interlock and Suki's resistance, unchanged by this file. The slot *prints*; it does not gate. What it prints is always the first failure in Suki's priority order (service → usage → overlay → list), one failure at a time, never a list.

### 1.3 The four states, exact strings

**State 1 — Unprimed idle, healthy** (all four checks true, enforced list proved against the service's own set):

```
{n} APPS WILL SHUT
```

- Future tense — T-14: nothing is shut yet, so the line says *will*. `1 APP WILL SHUT` in the singular; print agrees with its number.
- If the loadout also carries sites: `{n} APPS · {s} SITES WILL SHUT`. The site segment is part of the same fact (what the seal will stop), not a second fact.
- Source: the blocking service's live enforced count — the set it will actually match against, hash-proved at bind — never the settings count.

**State 2 — Primed, 04:58** (routine window has seated wheel, loadout, and hero — the fasted block, 05:00–08:00, nothing sealed, nothing counting):

```
{n} APPS WILL SHUT
```

- **The identical string, character for character.** That sameness is the spec, and it is the beyond: every other element of the 04:58 frame is exceptional (primed wheel, demoted at rest, the whole morning as one hero), and this line refuses to be. `n` is re-measured at the seating event against the *routine's* loadout, so if the fasted loadout stops nine apps where his manual one stops seven, the numeral changes — the sentence does not.
- It prints **no** routine name, **no** start time, **no** countdown, **no** `AT 05:00`. Next-firing lives in chrome's NEXT slot only (P2-3); a time in this slot would make `WILL SHUT` a promise about a clock instead of a fact about a loadout, and at 05:00 — or 05:20, or mid-window at 06:10 — the frame does not change when the window opens. The offer ripening is not an event this line reports.
- If he never comes and the window closes at 08:00, the Deck returns to State 1 and the slot re-measures to the manual loadout. Nothing was printed about the miss. Deviation is free, and free things leave no print.

**State 3 — Mid-slide**

- **Healthy: the string does not change during travel.** Not at the 35% poll detent, not at the 0.65/0.68 gate, not in the crank zone. The count was true before the thumb moved and the drag proves nothing new about it; a line that updates under a moving thumb is a second rendering chasing a gesture, unreadable exactly when it changes, and layout-shifting inside a fixed 12dp box. The next change is the seal's (§1.4), fired from the seat frame — never from a threshold crossing (Prima's celebration-before-the-fact charge, answered in print: this line celebrates nothing before the pawl seats).
- **Broken: the string does not change during travel either — because the TRUTH tenant was already in the slot before the slide began.** Readiness is measured before he arrives (Suki); a failure discovered mid-drag would be a failure of the measurement, not a cue for new type.
- **Rosa's interlock sentence — its home is this slot, at plate size, and it was already home before the refusal happened.** The exact string, when the service check fails:

```
BLOCKING IS OFF — NOTHING WILL BE HELD
```

  At the interlock point (65%, BLOCK failed) the cap stops, the knock lands (**16ms @ 1.0**, Rosa's, unchanged), continued push scrapes as filed — **and no new line appears anywhere.** Rosa's filed form printed this sentence a second time, under the track, in Atkinson 13sp, at the refusal moment. That printing dies here, on three grounds, the first two of them truth grounds, not taste:
  1. **It is a second rendering of a fact already printed.** The slot has carried the sentence since Deck entry. Re-printing it larger, lower, louder at the refusal is the one-fact-two-homes breach the whole wave runs against — and it teaches the eye that the plate version was the draft and the big version is the real one, which devalues every plate fact on every screen.
  2. **It arrives too late to be the refusal.** A sentence that appears when the stop is met is a caption for a haptic. The refusal's information must precede the gesture it refuses — and in this spec it does, by the whole dwell time on the Deck, not by 0ms.
  3. **It fits the plate, so the promotion has no truth excuse.** 38 characters × ≈8dp = **304dp in a 320dp column**, single line, tracking untouched. An argument to promote it would have to be *"10sp might be missed"* — a legibility argument, and a real one (see §3, the case against). But size law may only be broken by a truth that cannot otherwise be printed, and this truth demonstrably prints. What carries the refusal's weight is the interlock itself — a hard stop in the hand outranks two extra points of type, and a man who has felt the stop does not need the sentence repeated; a man who hasn't reached it can still read the sentence, because it was never anywhere else.
  
  Suki's per-failure Deck instructions (`TURN ON BLOCKING TO ARM`, Atkinson 13sp, in the slide track's label slot) are a different object — an *instruction*, spoken where the thumb is, pointing at a repair. They stand untouched. This slot prints *facts*; the track label gives *directions*; the interlock gives the *consequence*. Three jobs, three homes, no sentence doing two of them.

**State 4 — Sealed** (printed at the seat frame, from the blocking cascade's proved result — CONFIRMED links only, never COMMANDED):

```
{n} APPS HELD
```

- `n` counts **everything the seal stops**: SHUT-tier apps **plus PEEK-tier apps** (T-14: PEEK intercepts included), plus sites in the extended form `{n} APPS · {s} SITES HELD`.
- The verb is **HELD**, deliberately, and this is the tense argument in one word: `SHUT` would lie about the PEEK tier — a peek app is not shut, it is held, and can be leased for two minutes by the lawful break in the wall. `HELD` is true of both tiers, for the whole session, including during a peek lease (the lease is the seal's own act, not its absence). Present tense, continuous: the seal is doing this now.
- **The line stays.** It does not leave at the seal, does not fade with the Vertigo shot's orange drain, and is not dismissed. It is the running Deck's one standing statement of what the session is — the colophon of the sealed state. It leaves only at session end, when State 1's tenant is re-measured and re-struck in its place (§1.5).
- **Frozen, not live.** The count is the seat-frame count for the session's whole life. A peek lease does not decrement it; a mid-session revocation does not reprint it (the gap is admitted at unlock and on the receipt, per Suki — never as a live correction competing with the session). A frozen true-at-sealing fact, labelled by its tense as a standing condition, is honest; a live count twitching under leases and revocations would be a score with a footnote.

**The TRUTH tenant, all forms** (first failure only, priority order service → usage → overlay → list; each prints the *exact consequence* of that failure, no generic `NOT READY`, no check-count — `2 OF 4 CHECKS MISSING` counts the machine's process, not the user's world, and dies here):

| Failure | Exact string |
|---|---|
| Blocking service dead | `BLOCKING IS OFF — NOTHING WILL BE HELD` |
| App-usage access off | `APP-USAGE OFF — NOTHING WILL BE HELD` |
| Overlay off | `OVERLAY IS OFF — NO WALL WILL SHOW` |
| Block list empty | `BLOCK LIST EMPTY — NOTHING WILL SHUT` |
| List loaded ≠ list proved (hash mismatch) | `LIST UNPROVED — NOTHING WILL BE HELD` |
| Partial enforcement (advisory; seal may still pass per Rosa) | `{k} OF {n} APPS WILL SHUT` |

Note the tenses doing work: list facts stay in the future (`WILL SHUT` — the list is a promise about a seal that hasn't happened); integrity failures take `WILL BE HELD` in the negative, because *held* is the seal's own verb and the sentence denies the seal, not the list. An unmeasured state (`CHECKING…`, query timeout) prints `LIST UNPROVED`'s family, never a pass: **unknown is printed as unproved, full stop** — Rosa's `UNKNOWN` principle, in the slot's grammar instead of a seventh string.

### 1.4 Transitions between tenants

| Change | Mechanism | Timing |
|---|---|---|
| IDLE ↔ TRUTH (re-measurement events only: foreground, permission broadcast, service bind/unbind, Deck entry) | Slug swap — old drops 3dp and fades **60ms**, new drops in **90ms**, `CubicBezier(0.55, 0.0, 1.0, 0.6)` | 150ms total, event-driven only, never per-second, never on scroll |
| IDLE/PRIMED (routine seats or unseats) where only the numeral changes | Same slug swap, numeral segment only — the sentence frame does not move | 150ms |
| Any unsealed tenant → SEALED | **Not a swap. The Strike (§2).** | At the seat frame, t=0 |
| SEALED → IDLE (session end) | Slug swap, fired at the end event — visible inside the receipt's 220ms empty beat, before the sheet rises, so the Deck is already truthfully idle when the receipt strikes over it | 150ms, completed before the receipt's strike |

Haptics for all tenant changes except the Strike: **explicit silence** (chrome law — print is seen, not felt). Sound: **explicit silence**. The interlock knock and the seal are the hand's events; the line is the eye's, and it does not borrow theirs.

### 1.5 What this replaces, and why that loses

- **My own filed `SHUT 7 APPS` / `NOTHING SHUT` (present tense, idle)** — a lie by tense, already conceded in T-14; this file is that concession typeset in full instead of amended in a footnote.
- **Suki's chrome `READY · 47 APPS BLOCKED` and `NOT READY · 2 OF 4 CHECKS MISSING`** — `BLOCKED` in the present tense while unsealed is the same T-14 lie in a healthier coat, and the check-count renders the instrument's diary instead of the outcome. Her *measurement* — four real checks, pre-arrival, hash-proved — is adopted whole; her *sentences* are replaced by outcome sentences. (Mailed to her with this file — §4. The tenancy is half hers; I am not seizing it, I am typesetting it and sending her the proof.)
- **Rosa's under-track refusal line (Atkinson 13sp, appearing at the interlock)** — a second, promoted rendering of a sentence the slot already holds. Dies per §1.3, State 3. Her interlock, detents, haptics, and advisory/hard distinction stand untouched.
- **Humans' 04:58 top line, `BLOCKING ON` / `BLOCKING IS OFF — TAP TO FIX`** — as applied to *this slot*: `BLOCKING ON` is a health fact wearing a state word's clothes, printed green-by-another-name in a line that already says the outcome (`n APPS WILL SHUT` *is* blocking-on, said in consequences); and `TAP TO FIX` is an instruction, and this slot is print, not a button — a nameplate that invites a thumb teaches the thumb to press furniture. The repair tap-target lives where Suki put it; the fact lives here. Her frame's drawing is otherwise adopted as State 2's ground truth.

## 2 — THE STRIKE: A MARK AT THE SEAT FRAME

### 2.1 The argument from print

A press that leaves no impression was never pressed. The seal is the one act in this app that is a pressing: a loadout driven home against the OS, proved link by link, seated by a pawl. Wren's shot is what the seal *looks like* — attention arranged in time, a picture of a fact that has already happened, by her own spec. Orson's sound is what it *sounds like* — the thock, the bolt sized by what it seals. Neither is a mark. A shot ends; a sound ends; and the Deck that results is, to the eye of print, *identical in kind* to the Deck before — its one changed sentence arrived by the same polite crossfade as a routine reschedule. An editorial update and an act of sealing, rendered in the same physics, claim to be the same kind of event. They are not, and print is the craft that knows the difference: **edits are swapped; impressions are struck.**

So: **yes, arming leaves a printed mark on the Deck at the seat frame. The mark is the sealed tenant itself, struck — and a pressure lip beneath it that lives exactly as long as the seal does.** No new element is added to the Deck. Nothing is added anywhere else, ever.

### 2.2 Spec

- **What.** At the seat frame (t=0 — the frame the cascade's proof completes and the session state flips, per Cato: the callback fires on the seat frame, never at a threshold), the SEALED tenant (§1.3, State 4) is set by **strike**, not slug swap:
  - All glyphs arrive in one blow: **110ms**, `CubicBezier(0.9, 0.0, 1.0, 0.4)`, scale **1.04 → 1.0**, no overshoot — iron does not bounce. (The receipt's strike, promoted upstream to the act it was always rehearsing: the session-end receipt is the *second* strike of the session, and now the form rhymes — struck shut, struck closed.)
  - Ink-settle underneath: centres 82% → 88% over **400ms**.
  - Simultaneity is law: the strike fires *on* the proved seat frame, with Orson's seal and the seat knock — never before the proof (no strike on a threshold, a threshold strike would print a seal the cascade hasn't proved — celebration before the fact, in ink), and never after as a garnish. If proof fails, there is no strike; there is the interlock, and the TRUTH tenant that was already printed.
- **The lip — the mark proper.** On the strike frame, a **1px light lip** appears directly beneath the slot's baseline, spanning the slot's full width (20dp margin to the column's right terminus), at baseline **+3dp**: day, ground-lightened tone at 50%; night, **#4A423C at 35%** over ground `#171412`. It is the lower lip of an impression — the same device that closes my receipt sheet, at furniture scale: the line reads as *pressed into* the Deck for as long as it is sealed-type. It is geometry, not data: it carries no count, no word, no state beyond the pressure that made it.
- **How long it lives — the whole seal, and not one frame longer.** The lip is co-terminous with the sealed state: it fades out over **240ms** at the session-end event (the same beat the SEALED tenant slug-swaps back to IDLE, §1.4), and the ground beneath it returns unmarked. This is the line between a mark and a record, and it is the whole design:
  - A mark that **outlives** the seal — a notch per session, a scar in the track, a tally in the garage — becomes a *record*, and record has exactly one home (the Ledger / the receipt's moment). A Deck that kept strike-marks would be a second archive growing in the furniture, one notch at a time, unaudited. **Refused by name: no cumulative mark, no per-session notch, no strike counter, anywhere.**
  - A mark that lives **only while its fact is true** is not a record; it is a *state rendering*, like Rosa's lit fault cell that dims but remains on the running Deck. When the fact stops, the mark stops. Nothing is kept; nothing needs keeping — the receipt at session end is where this session gets remembered, once, in words.
- **Where it is not.** Not in the slide track (Sana's D4 gate notches own the track's geometry; a second mark system there would double-draw the commit). Not on the cap (the cap returns; a mark on a moving part is a label, not an impression). Not in chrome beyond the imprint line itself.
- **Reduced motion.** The strike becomes a single opacity step at the seat frame; the lip appears in one frame. The facts and the mark arrive identically; only the theatre yields.
- **Haptics / sound.** None of its own. The strike *is timed to* the seat knock and Orson's seal, and borrows neither a second thump nor a second sound — one event, three crafts, no craft doubling another's beat.

### 2.3 What this replaces, and why that loses

- **The slug-swap as the seal's print transition** (my filed chrome motion) — an editorial gesture for an act of force; it survives for every editorial change (§1.4) and dies for this one.
- **The "no mark" position — the seal carried entirely by Wren's shot and Orson's sound** — loses on persistence: cinema and sound are both *over* in about a second, and for the remaining forty-nine minutes the running Deck bears no trace in its own furniture that a pressing occurred; its SEALED word sits in the same crossfaded type as `IDLE` did, and the two states read as adjacent settings rather than as *before* and *after* an irreversible-feeling act. Print's mark is the only one of the three still present at minute forty — which is when presence matters.

## 3 — THE STRONGEST CASE AGAINST THIS PROPOSAL

*In full, because a spec that hides its wound will be opened at it anyway.*

1. **The refusal may be illegible at the only moment illegibility costs a morning.** Floor's dissent stands on the record in Designers (plate 10sp, reversal condition: one observed mis-read promotes words to 15sp). My whole State-3 argument is that the TRUTH sentence was printed *before* the slide — but at 04:58 it is printed at 10sp to the least-adapted eyes of the day (Humans' own frame says so), in a slot he has trained himself to ignore precisely because it is furniture, and furniture is what a nameplate is *for*. Rosa promoted her sentence because refusal is not furniture — it is the machine saying no, and machines that say no at furniture volume get forced. If the device trial shows him pushing through the interlock twice before reading why, §1.3's size argument collapses on its own terms: a truth that is printed but not *received* has not been told, and TELL THE TRUTH once means told, not typeset. I have bet the refusal on the haptic stop carrying what the type whispers. It might be a bad bet.
2. **`HELD` may overclaim at the exact scope T-14 widened.** I folded PEEK apps into the sealed count on the argument that a lease is the seal's own act. But for the two minutes of a peek, that app is *open* — usable, scrollable, real — while my line, frozen by my own law, goes on printing it as held. A hostile audit (Nox's, and it will be Nox's) can say: the future tense was fixed by widening the count, and the widened count reintroduced the lie in the present tense, one app at a time, for two minutes at a time. The alternative — the line leaves at the seal, or counts SHUT-tier only and lets PEEK live in the airlock where it acts — is uglier print and possibly honester arithmetic. I chose the verb that covers both tiers; the verb may be covering *for* them.
3. **The Strike's lip is a duplicate rendering of the seal, by my own definition.** §1.3 kills Rosa's line for rendering one fact twice. The lip renders *sealed-ness* a second time — the word `HELD` already says it; the lip says it again in geometry, for fifty minutes. I have called it "pressure, not data," but a persistent visual difference that exists iff a state holds *is* a rendering of that state; the receipt's lip is honest because the receipt is struck once and dismissed, while mine sits there being a tally of one, all session, one frame past the session's end away from being a record with the serial number filed off. If Lind charges the lip as the imprint's second home for the seal fact, my defence is a metaphor, and she has beaten metaphors with measurements all wave.

I file it anyway: because a slot that changes its sentence with its tense is the first version of this line that never lies in grammar, and a seal with no impression is the one version of this gesture print cannot sign. Let the charges come at the strong version.

## 4 — STANDARDS CHECK

- **ARM ≤10s: PASS, zero cost.** No tenant change is on the arm path as a step: measurement is pre-arrival (Suki), the mid-slide slot is inert by design, and the Strike is a *rendering of* the seat frame that already exists — it adds 0ms serial time, 0 gestures, 0 reading demand. Cold-open-to-sealed stays at the filed ≈1.2s typical / ≈2.5s worst case.
- **HOLD absolute: PASS.** Mid-session the slot is frozen print with no action, no tap target, no live count, and — by the tenancy law's rank 2 — not even a truth failure may evict the sealed tenant mid-session. The slot introduces zero mid-session decisions and zero mid-session interruptions.
- **TELL THE TRUTH once: PASS, with the risks owned in §3.** One slot, one tenant, one string, one source per fact (service-enforced count, hash-proved list, first-failure priority). Tenses audited per state: future while nothing is shut, exact-outcome negatives while broken, present-continuous `HELD` while sealed, `UNPROVED` never dressed as pass. The duplicate renderings this file kills are named in §1.5 and §2.3 — including two of my own.
