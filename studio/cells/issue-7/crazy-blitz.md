## Part 1 — proving LIVE

### B-1 · THE CANARY — a decoy the wall must keep killing
- **Idea:** bundle a dummy target (own package/activity dressed as a generic
  social app), permanently ruled SHUT, hidden from the catalogue. Every ~60s
  inside a session, Shield launches it; the real block pipeline must catch it.
  The catch stamps `CANARY CAUGHT · HH:MM:SS` and acts as a third witness in
  the status derivation. A canary that reaches foreground flips the sentence
  to UNPROVEN immediately, failure named.
- **Why:** FORM/FUNKE/SALZ proved the sentence must not trust service
  self-report. This stops trusting report entirely — it tests the whole chain
  (detection → overlay → kill) end to end, continuously. FUNKE's deferred
  challenge–response (option C), promoted from successor to standing watch.
- **Build sketch:** decoy activity + probe hook on the existing beat loop +
  one stamp field consumed by `ShieldBlockingStatus`. ~1 builder-day.
- **Price/risk:** a 60s micro-launch costs battery; cadence can ride the edge
  of the 45s stale law. Kill criterion: if the probe ever shows in recents /
  flashes visibly, cadence drops or the idea dies.

### B-2 · PROOF AGE — the sentence carries a clock
- **Idea:** `BLOCKING NOW · PROVED 3s AGO` — seconds since last witness beat,
  ticking in Anonymous Pro, resetting at each fresh beat.
- **Why:** staleness becomes visible *before* the STALE threshold trips;
  a dying wall ages in plain sight.
- **Build:** the beat timestamp already exists in the derivation; a 1s ticker
  on one segment under SCHWUNG's anti-flap coalesce. ~2 hours.

### B-3 · THE TURNED-AWAY INK WELL
- **Idea:** PANZER's solidity glyph accumulates: each real turn-away this
  session inks it one step (6 steps, outline → solid). At lawful end the
  final fill prints on the finish receipt.
- **Why:** proof you can watch accumulate; spends block events as ink instead
  of a log nobody opens. Counts are lawful on Shield (the no-count room is
  the Drawer).
- **Build:** fill = session turn-away count → glyph step, Canvas path.
  ~half a day.

### B-4 · TUG THE DOOR — pull-to-prove
- **Idea:** pull-down on the Shield column fires the B-1 probe *now* and
  prints one kept line: `ASKED THE DOOR · IT HELD · 04:12:33`.
- **Why:** certainty as a ritual he controls at 1 AM — one pull, one line.
- **Build:** pull gesture + probe-now entry point (shared with B-1) + one
  persisted line. ~half a day on top of B-1.

### B-5 · THE WATCH LOG — witnesses sign a roster
- **Idea:** two ruled micro-rows under the sentence: `SHIELD — SIGNED
  04:12:31` / `ACCESSIBILITY — SIGNED 04:12:30`, re-striking per beat.
- **Why:** when proof fails you see *whose signature stopped and when* —
  diagnosis as reading a logbook. Collapses into the sentence's long-press
  if height fights back.
- **Build:** two rows off the stamps MONTEUR already reads. ~half a day.

## Part 2 — the loadout as an object

### B-6 · THE KEY PROFILE
Cap rendered as a machined key: one tooth per catalogue group, cut deep =
SHUT, notched = PEEK, flat = OPEN, width ∝ group size. Each profile cuts a
different key — readable by silhouette. Ghost Preview = key held hollow;
commit = one latch (KLANG: never the seal voice). Canvas path from
`groupedByRule()`. ~120 lines, no new data.

### B-7 · THE KEY RING
Routines block = a ring; each routine hangs its miniature key. The ARMED
routine's key leaves the ring and sits in the cap, its source print as the
engraved plate. On fire, the key travels ring → lock inside the seal's
motion. Shared key composable, two sizes + cap slot state. ~1 day over B-6.

### B-8 · THE COUNTERFOIL
Every loadout commit (hand or routine) tears a numbered counterfoil into the
session record: app-by-app tier diff, side-effects included or they don't
happen. Undo = re-seat the foil's key, exactly. Foils file with the finish
receipt in the Drawer — one paper family. Diff is mechanical over the tier
map + one restore path. ~1 day. Answers audit item 4's "no preview, no
confirm, no undo" with an object, not a dialog.

### B-9 · TWO KEYS TO WEAKEN
Mid-session, the cap's key turns toward more-SHUT alone; turning toward OPEN
requires the second key — the Safe Break / emergency path — visibly inserted
beside it. The ratchet refusal moves from item-0 print to the control itself,
in the hand (TAST's ruling). Cap pose + existing break path. ~half a day.

### B-10 · ENGRAVING
A hand-made loadout can be stamped with his own short name (`EXAM EVE`),
printed wherever the source prints, under SAUM's print-layer caps. One string
on the profile + one plate line. ~2 hours.

### B-11 · THE KEY COMES HOME
At lawful end, the routine's key travels back to the ring and his BY HAND key
re-seats, inside HAUT's 420ms RELEASE dawn. A session becomes a loan with a
visible return. Reuses B-7's travel in reverse. ~half a day.
